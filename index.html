AUTOSAR-Style RTE

An educational automotive stack in C++: an ARXML-driven code generator that emits the Runtime Environment gluing software components to a fixed-priority OS and a BSW slice (COM, NVM, DEM). Sender-receiver and client-server ports, exclusive areas over priority-ceiling resources, and remapping one ECU to two by changing only the ARXML.

ProcWatch

Real-time Linux process monitor. A kernel module hooks fork, exec and exit events into a lock-free ring buffer, exposed to user space through a character device (/dev/procwatch), a procfs statistics interface, and ioctl controls — with a user-space daemon and live dashboard on top.

Kernel Modulechardevprocfsring bufferioctlC
PID 0006COMPLETE

Network Threat Analyzer

An offline, read-only pcap mini-IDS in Python. Five behavioural detectors — C2 beacon timing analysis, DNS tunnelling by Shannon entropy, port scans, ARP spoofing, and cleartext credential leaks — feed a severity engine with corroboration, producing a self-contained SOC-style HTML report with a threat timeline and per-alert evidence. Purely passive: it reads captures, never sends a packet.
